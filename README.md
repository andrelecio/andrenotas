# AndreNotas

**AndreNotas v1.0** é um editor de texto gratuito para Windows, desenvolvido em Python e Tkinter por André Henrique G. Lécio (andrelecio).

## Funcionalidades

- Edição de um documento por vez, com abertura de TXT e arquivos de código-fonte.
- Numeração de linhas e realce de sintaxe opcionais.
- Localizar, substituir, ir para linha e zoom.
- Desfazer/refazer, copiar, colar e impressão.
- Salvamento padrão em TXT e opções de codificação.
- Recuperação de documentos, modo somente leitura e preferências persistentes.
- Interface clara com tons azuis pastéis e fonte **Kumbh Sans** (instalada separadamente).

## Execução pelo código-fonte

Requer Python 3 com Tkinter e Windows para a integração nativa. Execute:

```powershell
python AndreNotas.py
```

## Gerar o executável e instalador

No Windows, execute `GERAR_EXE.bat` para construir o EXE. Em seguida, com o Inno Setup 6 instalado, execute `GERAR_INSTALADOR.bat`.

O ícone do aplicativo está em `andrenote.ico`. Os recursos gráficos da barra estão na pasta `icons/`.

> A compilação do instalador e a impressão devem ser validadas em um computador Windows.
